# Migo: releases up to v0.9.19

Migo v0.9.19 and earlier were released under the Business Source License 1.1. This
commit holds that license text (`LICENSE`) and its notices (`NOTICE`); the release tags
up to v0.9.19 point here. The packages themselves are attached to each release.

Later versions are released under the Migo Binary License 1.0. See the `master` branch.
