`RuntimeConfig` 是不可变的会话配置:**一次创建、全程生效**。改任何一项都得建一个新 Config 重建 session。构造只走 `Builder`。

## 目录三兄弟与 displayDensity

Builder 有两个入口:

```java
new RuntimeConfig.Builder(Context)                          // cacheDir/filesDir/displayDensity 从 Context 推
new RuntimeConfig.Builder(cacheDir, filesDir, density)      // 完全自供,脱离 Context
```

| 字段 | 说明 |
| --- | --- |
| `cacheDir` | 缓存目录,系统可清 |
| `filesDir` | 持久目录,系统不清 |
| `codeCacheDir` | JS bytecode 缓存目录,默认推导自 `cacheDir`(即主缓存目录,系统可清),`setCodeCacheDir` 重写 |
| `displayDensity` | 像素密度,CSS px 换算基准;自供 Builder 时必须给真值 |

宿主有自己的游戏包/缓存目录规范就用三参 Builder — 把两个根目录取走,不让 SDK 替你挑。

## 渲染节奏

| 字段 | 默认 | 说明 |
| --- | --- | --- |
| `targetFps` | `60` | 引擎驱动 `requestAnimationFrame` 的上限 — 是上限不是保证 |
| `immersiveMode` | `true` | 全屏沉浸 |
| `startupOrientation` | `null` | 只能是 `"landscape"` / `"portrait"` / `null`;传其他值直接 `IllegalArgumentException` |

## 调试与 watchdog

| 字段 | 默认 | 说明 |
| --- | --- | --- |
| `debugEnabled` | `false` | 挂上 DebugOverlay / Console 日志视图 |
| `logLevel` | `WARN` | `TRACE / DEBUG / INFO / WARN / ERROR / OFF` |
| `watchdogEnabled` | `true` | 心跳超时上报 native 侧 |
| `watchdogTimeoutSecs` | `10` | 无心跳的容忍秒数 |

发布包不要关 watchdog — 它是引擎层面唯一能在系统 ANR 之前先把信号抛出来的机制。

## 代码签名

| 字段 | 默认 | 说明 |
| --- | --- | --- |
| `codeSigningEnabled` | **`true`** | 验签默认开,别误当成是 debug 开关 |
| `codeSigningPubkey` | `null` | Hex Ed25519 公钥,64 字符 |

常见错误是误以为发布包里签名验证默认关 — 恰恰相反:默认开,不开 pubkey 时签名验证直接拒收。生产配置 = 两个字段都设 · 调试想跳过 = 显式 `setCodeSigningEnabled(false)`,只当临时手段。

## 网络策略

**不设就什么网络都没有。** 没调用 `setNetworkPolicy` 的游戏,`request`、`downloadFile`、`uploadFile`、WebSocket、TCP、UDP 一律被拒。每个通道单独授权:

| 通道 `NetworkPolicy.Channel` | 覆盖的 API |
| --- | --- |
| `REQUEST` | `request` / `fetch` |
| `DOWNLOAD` | `downloadFile`、远程图片、音频流、`prefetchAssets` |
| `UPLOAD` | `uploadFile` |
| `SOCKET` | WebSocket |
| `TCP` / `UDP` | 原始套接字 |

```java
NetworkPolicy policy = new NetworkPolicy.Builder()
    .allow(NetworkPolicy.Channel.REQUEST, "api.example.com")
    .allow(NetworkPolicy.Channel.DOWNLOAD, "*.cdn.example.com")
    .build();
```

- 条目是域名:`api.example.com` 只匹配它本身;`*.example.com` 只匹配子域,不含 `example.com`。**不能写 IP 地址**,写错的条目在 `allow` 调用处直接抛 `IllegalArgumentException`。
- `allowUnrestricted(channel)` 放开该通道的所有域名,只给开发工具或已审核过内容的宿主用;IP 地址仍然拒绝。
- `setAllowPlainHttp(true)` 才允许 `http://` 与 `ws://`。
- `setAllowLocalNetwork(true)` 让 SOCKET、TCP、UDP 能访问本机所在局域网的其他设备(联机对战);REQUEST、DOWNLOAD、UPLOAD 无论如何都到不了局域网和回环地址。
- UDP 套接字只收得到它能发往的对端发来的数据报:给 UDP 授权了域名时是公网对端,`setAllowLocalNetwork(true)` 时是局域网,本机永远不行。一个对谁都发不出去的游戏绑定不了 UDP 端口。
- 如果机器给 HTTP 配了代理(`HTTP_PROXY` 之类),域名由代理去解析:允许的域名最终连到哪里,由代理决定。
- 重定向按发起请求的通道检查:一次被 302 到别的域名的下载,仍然要过 DOWNLOAD 的白名单。

被拒的请求会收到写明 API、通道和域名的错误,例如 `fetch: domain 'x.example.com' is not in the request allowlist`。

## 内容侧注入

一个仅存于 Builder 的列表字段,以 JSON 走 JNI 传给 native:

- **preludeScripts**:`List<String[]>`,每项 `{"name","source"}` — `game.js` 之前先跑的完整脚本源码,注入 polyfill 用,按 list 序执行。

分包(`subpackages`)与 Worker 目录(`workers`)不在这里配:它们是内容自己在 `game.json` 里声明的,引擎加载内容时经已校验的挂载读取,所有平台同一个来源。

## Builder 全景

```java
RuntimeConfig config = new RuntimeConfig.Builder(context)
    .setCodeCacheDir(customCodeCache)
    .setTargetFps(60)
    .setStartupOrientation("landscape")
    .setDebugEnabled(BuildConfig.DEBUG)
    .setLogLevel(RuntimeConfig.LogLevel.WARN)
    .setImmersiveMode(true)
    .setWatchdogEnabled(true)
    .setWatchdogTimeoutSecs(10)
    .setCodeSigningEnabled(true)
    .setCodeSigningPubkey(pubkeyHex)
    .setNetworkPolicy(policy)
    .build();
```
